# Product roadmap

## Milestone 0 — Foundation (current)
- [x] Product direction and original visual identity.
- [x] Responsive UI prototype and design tokens.
- [x] Repository documentation.
- [ ] Port prototype into Next.js/TypeScript workspace.
- [ ] Add automated lint, typecheck and component test workflows.

## Milestone 1 — Product shell
- [ ] Next.js app shell, routing and responsive navigation.
- [ ] Shared design tokens and accessible component primitives.
- [ ] Authentication and profile onboarding.
- [ ] Mobile/tablet/desktop design QA.
- [ ] PWA manifest, icons and install experience.

## Milestone 2 — Auction configuration
- [ ] Public/private rooms, invite links and membership permissions.
- [ ] Franchise assignment and owner controls.
- [ ] Configure purse, squad size, player pool, increments and overseas limits.
- [ ] Lobby readiness and host controls.

## Milestone 3 — Player and squad operations
- [ ] Searchable player database with licensed data source.
- [ ] Player profiles, roles, attributes and filters.
- [ ] Squad builder, purse tracking and constraint validation.
- [ ] Nomination queue and unsold-player workflow.

## Milestone 4 — Live auction engine
- [ ] Server-authoritative bid transaction and atomic purchase.
- [ ] Live room state, event stream and countdown reconciliation.
- [ ] Reconnect recovery, bid history and host pause/resume.
- [ ] Race-condition, load and abuse testing.

## Milestone 5 — Intelligence and social
- [ ] AI franchise managers with configurable strategies.
- [ ] Squad balance/value analytics.
- [ ] Room chat, reactions and spectator mode.
- [ ] Auction history, squad cards and leaderboards.

## Milestone 6 — Mobile release
- [ ] Expo iOS and Android applications.
- [ ] Push notifications and deep links.
- [ ] Device QA, accessibility and reconnect behavior.
- [ ] TestFlight and Play internal testing; store compliance and release.

A milestone is not complete because a screen exists. It needs acceptance criteria, automated tests for critical rules, responsive QA and operational documentation.
